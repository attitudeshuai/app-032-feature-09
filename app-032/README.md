# 花灯骨架放样与蒙面裁片 · Lantern Frame Lofting

纯前端工具：选灯型 → 填直径/高度/收口 → 出「每根竹篾截多长、弯什么角度」的骨架件表、带缝份的蒙面裁片、以及可 100% 打印的 1:1 放样图与备料单。无后端、无网络请求，断网可用。

## 技术栈

- Vue 3（`<script setup>` 单文件组件）+ TypeScript + Vite 6
- 状态：Vue 自带 `ref / reactive / computed / watch`（无 Pinia / Vuex）
- 额外依赖仅 `vue-router` 4（规格书要求的 6 个路由）
- 手写 CSS；无 UI 组件库、无图表库、无游戏引擎/物理库
- 字体、灯型数据包（`src/data/lantern-types.json`）全部本地打包，无外网 CDN

## 自检 ↔ 参数对应表（G2，全应用唯一出处 `src/core/guide.ts`）

每条页底自检结论（CHK-01 ~ CHK-08）都能**顺着找回参数**：

1. **点一条未过结论** → 跳到「参数与灯体预览」页，相关参数滚动到视口中央并用金色/红色脉冲标出；纸张、搭接量落在 1:1 放样图页。
2. **按影响大小排队的相关参数，一个不漏**：高 / 中 / 低三档（数值扰动试算排名），每条写清怎么动、落点值（如母线等分数的整数目标）与「用 N 等分」一键应用。
3. **每改动一处牵动哪些别的结论**逐条列出（牵动关系取自 `AFFECTS` 全图）。
4. **参数一改全部八条重新核**：转通过的从未过名单移走、新冒出来的加进来（未过项永远排在最前）；备料/批量用量、图纸页数同步刷新。

> **岔路取舍（已挑定并认下代价）**：G1「每条结论只认一个主参数」去处唯一、好点好记，但有的结论真正起作用的参数不在主参数上，照着改未必过；本项目采用 **G2「全部相关参数按影响排队，一个不漏」**，代价是一条结论同时指向几个参数、改一个又牵动别的结论，来回试的次数变多——每条建议都显式列出「会牵动」的结论，把这个代价摆明。

**同一份说法落到处**（编号/标题/单位精度/参数叫法/牵动关系只取 `guide.ts` 名册）：预览页标出的参数、骨架页与裁片页各自显示的结论、备料与批量用量、三份 CSV 导出单子（构件/裁片/备料，均带版本号、参数指纹、参数取值、八条结论取值与单位口径）、可打印构件清单页脚的结论表、以及本机 localStorage 存档里的结论快照。

**作废规则**：存档与每份导出/打印单子都带参数指纹与对应表版本。参数一改，`ArchiveBanner` 逐条点明「本机存档那份」「已发出的某份单子/图纸」哪几条结论/取值已老，单子与图纸须**作废重出**，已照旧参数裁好、配好的料要重来；同类单子重出后顶掉老记录。旧版（无版本戳或 G1）存档载入即判老结论。

**旧存档迁移**：缺参数按 `MIGRATION_DEFAULTS` 写明的默认值补齐（等分 24、缝份每边 10mm、绑扎每端 20mm、搭接 10mm、A4、批量 20 等）再参与核对，补入项在横幅里逐条列出。

**精度口径**：面积核对按「裁片净面积 / 灯体表面积」比值分档（<94% 明显偏小 / 94~97% 逼近下限 / 97~103% 合格 / 103~106% 逼近上限 / >106% 明显偏大）；母线等分数按整数逐档往上加，试算到首个落进 [97.00%, 103.00%] 的整数；比值按百分数保留 **2 位小数**，面积折 **m² 保留 3 位小数**，长度 mm 保留 1 位（几何手算 3 位）。
